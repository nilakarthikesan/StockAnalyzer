# StockAnalyzer

Stock Analyzer: Automated Stock Data Insights 📈
This project is a Python-based stock analysis tool that retrieves and visualizes financial metrics such as Price-to-Earnings (P/E) ratio, Earnings Per Share (EPS), and historical stock performance using the Yahoo Finance API.

Key Features:

✅ Fetches real-time stock data for multiple tickers
✅ Calculates and plots EPS trends over time
✅ Computes optimal portfolio weights for investment strategies
✅ Utilizes matplotlib for data visualization
✅ Handles missing data and provides error handling for failed downloads

Technologies Used:

- Python 🐍
- yfinance for stock data retrieval
- matplotlib for visualization
- pandas for data manipulation
This tool is useful for investors, traders, and finance enthusiasts looking to analyze stock performance efficiently.
